ПРЕДВАРИТЕЛЬНЫЕ УСЛОВИЯ
--------------------------------------------------------------------
1. Node.js установлен (v20+)
2. В .env заполнены:
   - NEXT_PUBLIC_SUPABASE_URL (tpxwrwxpdcwmiynjjquy.supabase.co)
   - NEXT_PUBLIC_SUPABASE_ANON_KEY
   - SUPABASE_SERVICE_ROLE_KEY
   - ANTHROPIC_API_KEY (для AI-анализа)
3. В Supabase существуют таблицы:
   profiles, companies, survey_answers, diagnostics, admin_requests


ЗАПУСК ПРИЛОЖЕНИЯ
--------------------------------------------------------------------
cd в папку проекта
npm install
npm run dev

Открыть http://localhost:3000


====================================================================
ТЕСТ 1: РЕГИСТРАЦИЯ КЛИЕНТА
====================================================================

1. Открыть http://localhost:3000/register
2. Заполнить:
   - Имя: Тестовый Пользователь
   - Email: test@example.com
   - Пароль: Test123456
   - Роль: Клиент
   - Организация: Тест Компания
3. Нажать "Зарегистрироваться"
4. Ожидаемый результат:
   - Редирект на /client/waiting-room
   - Статус "Заявка получена"

ПРОВЕРКА В SUPABASE:
   - profiles: новая запись, status = 'pending_approval'
   - admin_requests: новая запись, type = 'registration'


====================================================================
ТЕСТ 2: ГИГА ПАНЕЛЬ (ПРОСМОТР ЗАЯВОК)
====================================================================

1. Войти как super_admin (нужен аккаунт с ролью super_admin)
2. Перейти в Гига Панель
3. Вкладка "Регистрация" — должна появиться заявка
4. Нажать "Читать подробнее" — раскроется карточка
5. Если клиент заполнил анкету — внизу карточки появятся
   данные анкеты по шагам
6. Кнопки: "Принять", "Отклонить", "Архив"

ПРОВЕРКА:
   - Заявка отображается с именем и email
   - При раскрытии — данные анкеты загружаются


====================================================================
ТЕСТ 3: ЗАПОЛНЕНИЕ АНКЕТЫ (6 ШАГОВ)
====================================================================

1. Войти как клиент
2. Перейти на /client/onboarding
3. Заполнить все 6 шагов:

   ШАГ 1 — Компания:
   Название, отрасль, стадия, кол-во сотрудников, регионы,
   бизнес-модель, контактные данные

   ШАГ 2 — Финансы:
   Выручка 2023/2024/2025, новые/повторные клиенты,
   средний чек, маржа, CAC, LTV, долг, точка безубыточности

   ШАГ 3 — Продажи:
   CRM, продукты, сделки/отказы по годам, цикл сделки,
   каналы, лояльность

   ШАГ 4 — Операции:
   Отделы, оргструктура, метод управления, совещания,
   отчетность, таск-менеджер, KPI

   ШАГ 5 — Маркетинг:
   ЦА, сегменты, регионы, каналы, бюджет, конкуренты, УТП

   ШАГ 6 — Цели:
   Главная боль, цели на 12 мес и 3 года, барьеры роста

4. После 6-го шага — автоматический расчет Point A

ПРОВЕРКА В SUPABASE:
   - survey_answers: записи с question_key (s1_*, s2_*, ...)
   - companies: запись с данными из шага 1
   - diagnostics: новая запись с overall_score


====================================================================
ТЕСТ 4: ТОЧКА А (ПРАВИЛОВЫЙ СКОРИНГ)
====================================================================

1. После заполнения анкеты — перейти на /client/point-a
2. Ожидаемый результат:
   - Гейдж с общим баллом (0-10)
   - 5 блоков: Финансы, Продажи, Операции, Маркетинг, Стратегия
   - Каждый блок раскрывается: проблемы + рекомендации
   - Секция "Риски" с цветовой кодировкой
   - Секция "Инсайты"
   - Секция "Быстрые победы" с таймлайнами
3. Кнопка "Пересчитать" — пересчитывает баллы

ПРОВЕРКА:
   - Баллы соответствуют введенным данным
   - При раскрытии блока видны проблемы и рекомендации


====================================================================
ТЕСТ 5: AI-АНАЛИЗ (CLAUDE SONNET)
====================================================================

ТРЕБОВАНИЕ: ANTHROPIC_API_KEY должен быть в .env

1. На странице /client/point-a нажать "Пересчитать"
2. Правиловые данные появляются сразу
3. Над блоками — фиолетовая секция "AI анализирует ваш бизнес..."
   с skeleton-анимацией (5-15 секунд)
4. После завершения:

   a) EXECUTIVE SUMMARY — фиолетовая карточка с 3-5 предложениями
      общего анализа бизнеса

   b) В КАЖДОМ БЛОКЕ при раскрытии — секция "AI-анализ":
      - Диагноз (что показывают данные)
      - Бенчмарк (сравнение с отраслью)
      - Риск (главный риск блока)
      - Рекомендация (конкретная, с инструментами и сроками)

   c) СТРАТЕГИЧЕСКИЕ ПРИОРИТЕТЫ — 3 карточки с:
      - Название приоритета
      - Обоснование (почему)
      - Ожидаемый эффект

   d) ДОРОЖНАЯ КАРТА РОСТА — 3 колонки:
      - 30 дней: 2-3 шага
      - 90 дней: 2-3 шага
      - 180 дней: 2-3 шага

   e) ОТРАСЛЕВОЙ КОНТЕКСТ — сравнение с бенчмарками

5. Если AI упал — красный баннер "AI-анализ недоступен" +
   кнопка "Повторить"

ПРОВЕРКА В SUPABASE:
   - diagnostics: ai_status = 'completed'
   - diagnostics: ai_analysis содержит JSON с полями:
     executive_summary, blocks, strategic_priorities,
     growth_roadmap, industry_context


====================================================================
ТЕСТ 6: СТРАНИЦА "МОИ ДАННЫЕ"
====================================================================

1. Войти как клиент
2. Перейти на /client/my-data
   (или из waiting-room нажать карточку "Мои данные")
3. Ожидаемый результат:
   - Данные анкеты по шагам (read-only)
   - Каждый шаг: русские названия полей, значения
   - Кнопка "Редактировать" — ведет на /client/onboarding?step=N
   - Если анкета не заполнена — предложение заполнить


====================================================================
ТЕСТ 7: ЗАЛ ОЖИДАНИЯ
====================================================================

1. Войти как клиент (до одобрения)
2. Перейти на /client/waiting-room
3. Ожидаемый результат:
   - Статус "Заявка получена"
   - 3 CTA-карточки:
     a) "Заполнить анкету"
     b) "Мои данные"
     c) "Загрузить документы"
   - Автообновление статуса каждые 30 секунд


====================================================================
ТЕСТ 8: ФОЛЛБЭК БЕЗ AI
====================================================================

1. Удалить ANTHROPIC_API_KEY из .env (или закомментировать)
2. Перезапустить dev-сервер
3. Нажать "Пересчитать" на /client/point-a
4. Ожидаемый результат:
   - Правиловые данные отображаются полностью
   - НЕТ фиолетовых AI-секций
   - НЕТ ошибок
   - diagnostics.ai_status = 'none'


====================================================================
ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ
====================================================================

- Prisma (DATABASE_URL/DIRECT_URL) может не работать —
  используется Supabase SDK как фоллбэк
- AI-анализ занимает 5-15 секунд
- Стоимость AI: ~$0.03 за один анализ
- AI-ключ Anthropic нужно получить на console.anthropic.com
