# Зеркало анкеты в Google Sheets через Apps Script

Портал при каждом сохранении анкеты отправляет одну строку на пользователя
(`user_id` в колонке A) в веб-приложение Apps Script, привязанное к таблице.
Ни Sheets API, ни сервис-аккаунт не нужны.

Целевая таблица: <https://docs.google.com/spreadsheets/d/1nZNByGAKvMdy-UW_wOdb9c1tWn204I_FLTLlDqCEx70/edit>

## Установка (5 минут, делает владелец таблицы)

1. Открыть таблицу → **Расширения → Apps Script**.
2. Удалить содержимое `Код.gs`, вставить целиком файл `survey-sheet.gs` из этой папки. Сохранить.
3. (Рекомендуется) **Настройки проекта (⚙) → Свойства скрипта → Добавить**:
   `WEBHOOK_SECRET` = любая длинная случайная строка. Ту же строку положить в Vercel как
   `GOOGLE_APPS_SCRIPT_SECRET`.
4. **Начать развёртывание → Новое развёртывание → тип «Веб-приложение»**:
   - Выполнять от имени: **Я** (владелец таблицы).
   - У кого есть доступ: **Все** (портал ходит без Google-логина; защита — секрет из шага 3).
   - Нажать «Развернуть», разрешить доступ к таблице, скопировать **URL веб-приложения**
     (`https://script.google.com/macros/s/…/exec`).
5. В Vercel (Production) добавить переменные и сделать redeploy:

   | Переменная | Значение |
   |---|---|
   | `GOOGLE_APPS_SCRIPT_WEBHOOK_URL` | URL из шага 4 |
   | `GOOGLE_APPS_SCRIPT_SECRET` | секрет из шага 3 (если задан) |
   | `GOOGLE_SHEETS_SPREADSHEET_ID` | `1nZNByGAKvMdy-UW_wOdb9c1tWn204I_FLTLlDqCEx70` (для ссылки в уведомлениях) |
   | `GOOGLE_SHEETS_SURVEY_TAB` | имя листа, по умолчанию `Анкета` |

6. Проверка: открыть URL `/exec` в браузере — должен вернуться
   `{"ok":true,"service":"aistart360-survey-sheet"}`. В редакторе можно запустить
   функцию `testUpsert` — появится строка `TEST-USER`.

## Важно

- После **любого изменения кода** скрипта нужно «Управление развёртываниями → ✎ → Новая версия»,
  иначе `/exec` продолжит отдавать старую версию.
- Первая строка листа — заголовки (`user_id`, `Обновлено`, `Email`, `Компания`, `Контакт`,
  `Телефон`, `Отрасль`, `Шагов заполнено`, далее «Шаг N · Раздел · Вопрос» для каждого
  вопроса анкеты). При добавлении вопросов в анкету заголовки перезапишутся автоматически.
- Одна строка = один пользователь: повторные сохранения обновляют её, а не добавляют новую.
- Telegram-уведомление «Анкета завершена» отправляет сам портал (`TELEGRAM_ADMIN_CHAT_IDS`),
  в сообщении есть ссылка на таблицу.
