## 1. Позиционирование и оффер

- **Категория:** «AI & Experts Growth platform».
- **Главное обещание (hero):** «Ускоряем рост бизнеса до $2M в год».
- **Срок:** «12–18 месяцев до цели» — через диагностику → воркшоп → пилот → системный трек.

- **Дефицит:** «LIVE — Только 10 компаний в год».

## 2. Целевая аудитория и боли

- **ЦА:** основатели и владельцы B2B-компаний с оборотом **$80k–150k в месяц** (фаза «Долины Смерти»).
- **Боли, на которые давит лендинг:**
  - хаос в процессах («теряют ~25% оборота» — есть интерактивный калькулятор «Цена Хаоса»);
  - невозможность масштабироваться;
  - нестабильный cashflow;
  - отсутствие измеримых метрик («олимпийский минимум метрик»).

## 7. Визуальная система лендинга (извлечено из production CSS)

### 7.1 Палитра (тёмная тема — основная)

| Токен лендинга | Значение |
|---|---|
| `--background` | `#000`, градиент `linear-gradient(180deg,#000 0%,#080808 100%)` |
| `--card-bg` / `--modal-bg` | `#0a0a0a` |
| `--primary` / `--foreground` | `#00ff41` (неоновый зелёный) |
| `--primary-hover` / `--hint-color` | `#10b981` |
| `--accent` | `#39ff14` |
| `--primary-gradient` | `linear-gradient(135deg,#00ff41 0%,#10b981 100%)` |
| `--border` / `--card-border` | `#1a3d1a` (тёмно-зелёная рамка) |
| `--card-shadow` | `0 0 25px #00ff4126` — **неоновое свечение, а не тень** |
| `--glass-blur` | `blur(8px)` |
| `--nav-bg` | `#000000f2` (полупрозрачный чёрный) |
| `--error` | `#ef4444` |

Есть и светлая тема (primary `#2563eb`, фон `#f8fafc→#f1f5f9`), но фирменное лицо бренда — тёмная «matrix-neon».

### 7.2 Типографика

- Лендинг: **Inter** (+ Inter Fallback), моно для кода/цифр.
- Портал уже использует свою связку: Bricolage Grotesque (заголовки) / DM Sans (текст) / Space Grotesk (лейблы) / JetBrains Mono (цифры, графики) — **сохраняем портальную**, она богаче и уже согласована.

### 7.3 Анимации лендинга

Keyframes из CSS: `spin`, `pulse`, `bounce`, `ping`, `fadeIn`, `slideInUp`, `pulseHint`, `scroll` + модульные `Preloader-module__pulse/spin`.

**Прелоадер лендинга (эталон для портала)** — точная спецификация из CSS:

```css
/* fullscreen-контейнер: фон страницы, fade-out 0.5s ease-out, z-index 9999 */
.container { position:fixed; inset:0; height:100vh; display:flex;
  align-items:center; justify-content:center;
  background:var(--background); transition:opacity .5s ease-out; }

/* 120×120, три концентрических кольца, разный цвет и скорость */
.ring        { border:3px solid transparent; border-top-color:var(--primary);
               border-right-color:var(--secondary); border-radius:50%;
               animation: spin 1.5s linear infinite; }        /* внешнее */
.ring::before{ inset:5px;  border-top-color:var(--success);
               animation: spin 2s linear infinite reverse; }  /* среднее, реверс */
.ring::after { inset:15px; border-top-color:var(--foreground);
               animation: spin 1s linear infinite; }          /* внутреннее */

/* по центру — текст-логотип, пульсирует прозрачностью */
.logo { font-size:.9rem; font-weight:700;
        animation: pulse 2s ease-in-out infinite; }
@keyframes spin  { from{transform:rotate(0)} to{transform:rotate(360deg)} }
@keyframes pulse { 0%,100%{opacity:.6} 50%{opacity:1} }
```

Характер: **техничный, лёгкий, «сканирующий»** — вращение с разными скоростями и направлениями + мягкая пульсация. Никаких тяжёлых lottie/видео.

## 8. Маппинг стиля лендинга на портал

Портал уже имеет зрелую тёмную glassmorphism-систему (MD3-токены в `tailwind.config.ts`): primary `#6effc0`, градиент `#6effc0→#00e5a0`, glow-тени `0 4px 16px rgba(110,255,192,.12)`.

**Решение:** портал сохраняет свою палитру `#6effc0` (более премиальная, уже прошита в 100+ компонентов), но перенимает у лендинга:

1. **Форму и характер прелоадера** — 3 кольца с разными скоростями/направлениями + пульсирующий логотип, на портальных токенах (`primary`, `primary-container`, `primary-fixed`).
2. **Неоновое свечение вместо теней** для акцентных состояний (у портала уже есть `primary-sm/md` shadows — использовать последовательно).
3. **Интерактивные подсказки** («нажми на блок для деталей») — микрокопию к кликабельным карточкам.
4. **Конкретный, уверенный тон** всех UI-текстов.
5. **Дефицит/статусность** («LIVE», лимиты) — в onboarding-коммуникации.

## 9. UX-ожидания, которые лендинг задаёт порталу

- Пользователь приходит с лендинга, обещающего **измеримость** → портал обязан показывать цифры честно (без mock), с внятными empty-состояниями «данных пока нет, вот что сделать».
- Лендинг быстрый и анимированно-живой → долгие операции портала (AI-генерация, парсинг документов) должны иметь **красивую индикацию прогресса**, а не замерший экран.
- Лендинг тёмный неоновый → порталу нельзя «мигать» белыми вспышками при загрузке (FOUC) и терять тёмный фон на skeleton'ах.
- Бренд-переход: клиент заплатил от 1.4М ₸ — интерфейс должен ощущаться дороже обычного SaaS-шаблона.
