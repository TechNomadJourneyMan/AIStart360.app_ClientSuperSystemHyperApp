# R3-PB. Точка Б: минимальная рабочая версия для платного клиента

Раунд 3, исполнитель Точки Б. Рабочее дерево `claude/round3-point-a-b` (от main 30df0055), worktree `multi-agent-portal-dev-8f4869`.
Ничего не закоммичено и не запушено. Staging, прод и Railway не трогал. Реальных вызовов ИИ не было: в тестах ключа нет, генерация подменена заглушками.

Решения PO, на которые опирается работа:
- планы готовят и одобряют Admin и Super Admin, самоодобрение допустимо;
- ИИ-стратегия — только черновик для персонала;
- публикация только с рассчитанными сценариями и выбранным темпом;
- выручка по месяцам вводится во «Финмодели» до одобрения плана;
- «Подробности» (V2) скрыты для клиента, код V2 и старейшего движка не удалялся;
- клиент видит только одобренное.

### M1. Черновик плана в один клик (ГИГА, Admin / Super Admin)
- **Было.** План собирался вручную примерно за 8 шагов, ИИ-черновика не было. Одобрить можно было и заметку без сценариев: «План v1 одобрен», а вкладки пустые (B5).
- **Изменение.**
  - **`lib/point-b/plan/quick-draft.ts`** (`buildQuickDraft`):
    1. Сначала считается модель. При уровне 0 или без сценариев — `409` со списком недостающего, в базу ничего не пишется.
    2. Дополняется открытый черновик или создаётся новый: снимок целей, причина «Первая версия плана» или «Обновление плана по текущим данным».
    3. Сохраняются три сценария модели и темп «умеренный». Уже выбранный рассчитанный темп сохраняется.
    4. Пустая стратегия заполняется деревом из правил с формулировками ИИ. Стратегию, которую уже написал персонал, функция не перезаписывает.
    5. Рекомендации правил и ИИ сохраняются в `pending_review` для этой версии.
    6. Версия на одобрении → `409`. Ничего не одобряется.
  - **`lib/point-b/strategy/draft.ts`** — дерево из правил:
    - рычаги выбранного сценария (лиды, конверсия, чек, повторные) становятся стратегиями с KPI «текущее → цель»;
    - ограничивающий фактор идёт первым, влияние 5;

  - а) после записи эксперта или админа владелец не мог сохранить за этот месяц ничего — даже дописать лиды;
  - б) одно сохранение персоналом перемечало все значения владельца как экспертные.
- **Сервер** (`lib/point-b/planfact/store.ts` `saveMonthlyFacts`):

- **Форма** (`components/point-b/monthlyFactController.ts`, `MonthlyFactForm.tsx`):
