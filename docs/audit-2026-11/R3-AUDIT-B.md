## 0. Вывод в пяти строках

1. **Точку Б никто ни разу не прошёл до конца. Код в целом не сломан.** На копии прода все таблицы `pb_*` пустые: 0 планов, 0 версий, 0 проверок целей, 0 финмоделей, 0 рекомендаций, 0 пересчётов. В журнале действий персонала нет ни одного `point_b.*` **[staging]**. Клиенты Точку Б не открывали ни разу: 2 просмотра super_admin (12.10) и 3 входа «от имени» (20.10) **[staging]**. За последние 72 ч на проде нет ни одного запроса к `/client/point-b` и `/api/v1/point-b/*` **[лог]**.
2. **Ценность раздела зависит от человека, а людей и сигнала для них нет.** 5 из 9 вкладок пустые («Эксперт готовит…»), пока Admin или Super Admin не одобрит версию плана. Её сборка — около 8 ручных шагов в ГИГА, стратегию пишут вручную, ИИ-черновика плана нет. Очереди «Pro-клиенты без плана» нет: в очередь и под SLA попадает только версия, уже отправленная на одобрение. Одобренных экспертов на проде 0.
3. **Главный вывод «Обзора» пустой у всех.** У 0 компаний есть выручка по месяцам. Поэтому вердикт у всех «Пока нельзя сказать, успеваете ли вы», а графика нет, потому что он строится только из одобренных сценариев. Помесячную выручку клиенту негде ввести, пока плана нет.
4. **Клиенту обещают то, чего нет.** «Эксперт готовит план» показывается всем, у кого есть цель или диагностика, даже если никто не назначен. Во вкладке сценариев пишем «От вас сейчас ничего не требуется».
5. **В одном разделе работают три расчёта.** «Обзор» и «Что если» считает новая модель. «Подробности», PDF, «Поделиться», чат, Гри и вкладки персонала считает старый V2: другой вердикт, ИИ-стратегия показывается клиенту без эксперта. Есть ещё старейший движок в `/clients/[id]/point-b`. Inngest **не** был причиной поломки (§4).

## 7. Предложение: как сделать Точку Б рабочей для платного клиента

### 7.1 Что считать «рабочей» Точкой Б (MVP)
Платный клиент открыл Точку Б и:
1. сразу видит честный предварительный расчёт: «Сейчас → Цель → Разрыв»;
2. если ввёл 12 месяцев выручки — видит вердикт и прогноз «при текущем ходе»;
3. видит, **кто** готовит его план и **к какому сроку**: 48 ч, как у остальной экспертной работы;
4. **в пределах срока** получает одобренный план: 3 темпа, выбранный темп, 3–7 задач в «Моих задачах», 1–5 проверенных рекомендаций;
5. каждый месяц вносит факт и видит «план — факт».

Персонал готовит такой план **за 15–20 минут**, а не за час ручного набора. PDF и «Поделиться» показывают те же цифры, что и страница.

1. **Волна 1:** S2 (решение PO, без кода) + S1 + S3.
2. **Волна 2:** M1 + M2.
3. **Волна 3:** M3 + L1.

- внешние приглашения и всплывающий слой;
- рекомендации ИИ по расписанию;
- сравнение версий;
- модели B2B и подписок.

### 7.4 Риски
- **Людей нет.** Одобренных экспертов 0. Без решения «кто готовит план» S1 и M1 дают очередь, которую никто не разбирает. → Q1.
- **Данных мало.** Только 4 из 19 Free-компаний имеют цель и базу. Остальным Точка Б покажет уровень 0 и список недостающего. Это честно, но выглядит пусто. Нужен понятный путь «заполнить 3 поля» в самом разделе.
- **ИИ-черновик стратегии.** Риск «ИИ придумал». Защиты: числа только из модели, проверка «число из данных» (готова в `recs/ai.ts`), публикация только после эксперта, бюджет-гард.
- **Нагрузка на БД.** Черновик в один клик = один расчёт модели (≈ 0,4–2 с), без фоновой массовой генерации.
- **Изменение решений PO.** Обязательные сценарии для одобрения, скрытие «Подробностей», отключение ИИ-стратегии — нужно «да».
