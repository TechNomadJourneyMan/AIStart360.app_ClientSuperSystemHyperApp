- **N5-1, срочно.** main опережает прод: код требует миграций 155–157, на проде применены только до 154. При этом:
  - ни `/api/health`, ни preflight не сверяют код с журналом миграций прода;
  - main не защищён.

  Выкатка main без этих миграций сломает CRM.
- **N5-2, P2, подтверждено оркестратором.** Клиент может сам сменить `profiles.email` через PostgREST: ни политика, ни триггер этого не запрещают. Последствия:

- **N5-3, P3.** Новые кроны `crm-digest` и `billing-expiry` не проверяют режим техработ.
- **UX-проход нашёл 15 мелких дефектов:** тексты, тупики, ссылки в закрытые разделы.
