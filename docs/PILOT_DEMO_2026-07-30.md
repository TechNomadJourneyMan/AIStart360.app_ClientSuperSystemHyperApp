# AIStart360 — сценарий пилотного показа

## Что показываем

Пилот доказывает один законченный бизнес-путь:

1. Предприниматель регистрируется как заявитель.
2. До решения он заполняет анкету; каждый ввод сохраняется локально и на сервере.
3. Giga Panel видит заявку, прогресс анкеты, документы и результат Point A.
4. Администратор одобряет заявку.
5. Пользователь становится Owner и попадает в канонический `/owner`-кабинет.
6. Владелец видит дашборд, Точку А, документы и приоритетные рекомендации.

## Десятиминутная демонстрация

### 1. Вход владельца

- Откройте `/login`.
- Войдите под контролируемым demo Owner.
- Покажите, что стартовый экран — `/owner/dashboard`, а не административный дашборд.

### 2. Исходные данные и восстановление

- Откройте «Анкета».
- Измените одно поле, подождите появления сохранённого состояния.
- Обновите страницу: текущий шаг и введённое значение должны восстановиться.
- Объясните, что завершённые ответы и незавершённый черновик хранятся отдельно.

### 3. Point A

- Откройте «Точка А».
- Покажите общий индекс, оценки по пяти блокам, риски и быстрые действия.
- Подчеркните: оценки считаются детерминированными правилами, поэтому AI не может самовольно менять финансовые показатели.

### 4. Рекомендации

- Откройте «Рекомендации».
- Покажите executive summary и план на 30–90 дней с ответственными, сроками и основаниями.
- При наличии AI Gateway нажмите «Обновить рекомендации».
- Без AI Gateway система честно использует резервный план по правилам и явно подписывает источник.

### 5. Giga Panel

- В отдельной сессии откройте `/giga-login`, затем «Заявки».
- Раскройте заявку: видны шаг анкеты, число документов и Point A.
- На тестовой заявке нажмите «Принять».
- После подтверждённого ответа профиль и Auth metadata получают роль Owner.

### 6. Границы пилота

- Откройте «Карта развития».
- Модули продаж, P&L, ДДС, рынка, CRM и команды не выдаются за готовые.
- Обсуждайте их как согласуемый следующий релиз после пилота диагностики.

## AI Gateway

1. Откройте `https://vercel.com/docs/ai-gateway/getting-started/text`.
2. Перейдите на страницу API Keys в AI Gateway и создайте отдельный ключ для проекта.
3. Локально добавьте `AI_GATEWAY_API_KEY` в `.env`.
4. В Vercel добавьте тот же секрет как Environment Variable для нужных окружений.
5. Модель по умолчанию: `anthropic/claude-sonnet-4.6`; её можно заменить через `AI_MODEL`.

Без ключа пилот остаётся работоспособным: числовая диагностика и резервные рекомендации не зависят от внешней модели.

## Подготовка demo Owner

После применения `004_entrepreneur_pilot.sql`:

```bash
DEMO_OWNER_EMAIL='demo@example.com' \
DEMO_OWNER_PASSWORD='use-a-unique-demo-password' \
npm run seed:pilot
```

Пароль не записывается в репозиторий и не печатается скриптом.

## Контроль перед встречей

```bash
npm run type-check
npm run lint
npm test
npm run build
```

Проверьте вручную:

- `/register` → `/client/waiting-room`;
- перезагрузка каждого шага анкеты;
- Giga approve → `/owner/dashboard`;
- `/owner/point-a`;
- `/owner/recommendations`;
- `/owner/documents`;
- `/owner/roadmap`;
- отсутствие 404 и пустых переходов в основной навигации.
