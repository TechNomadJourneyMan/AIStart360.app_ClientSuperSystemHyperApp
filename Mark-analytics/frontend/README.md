# Market KZ — Frontend

Web frontend for the Market Monitoring System (Kazakhstan).
Part of the `Mark-analytics` monorepo. Lives in `frontend/` next to `backend/`.

## Quick start

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

App boots at http://localhost:5173. The Vite dev server proxies
`/api/*` to the FastAPI backend at `http://localhost:8000` (configurable
via `VITE_API_BASE_URL`).

Make sure the backend is running:

```bash
cd ../backend
make dev   # or: uvicorn app.main:app --reload
```

Smoke-check the API contract any time at:
`GET http://localhost:8000/api/v1/meta`

## Stack

- **Build**: Vite 6 + TypeScript 5 (strict)
- **UI**: React 18, Tailwind CSS 4, shadcn/ui primitives, lucide-react icons
- **Routing**: TanStack Router (file-based, auto code-split)
- **Data**: TanStack Query v5, axios, zod schemas
- **State**: Zustand (client UI), nuqs (URL search params)
- **i18n**: i18next + react-i18next (ru / kz / en, default `ru`)
- **Dates**: date-fns
- **Utils**: clsx + tailwind-merge (`cn`)

## Theming

- Light / dark switched via `data-theme` attribute on `<html>`.
- Persisted in `localStorage` under `mk-theme`.
- Pre-paint script in `index.html` applies it before React mounts (no flash).
- Terminal-style density: 13–14px base, monospace for header / dense UI surfaces
  (`font-terminal` utility).

## i18n

- 3 locales: `ru` (default), `kz`, `en`.
- Detection: `localStorage` (`mk-lang`) → browser → `<html lang>`.
- Add a key: edit all three `src/locales/*.json` files.

## API client

- Use the `api` axios instance from `src/services/api.ts` (never bare `fetch`).
- It auto-attaches `Authorization: Bearer <token>` from `services/auth.ts`.
- Once the backend OpenAPI is stable, generate typed clients:
  ```bash
  npx openapi-typescript http://localhost:8000/api/v1/openapi.json \
    -o src/types/api.gen.ts
  ```

## Things this scaffold does NOT include

These are owned by sibling agents — do not duplicate work:

- **MapShell, MapLibre, deck.gl, supercluster** → `frontend-map` agent.
- **Supabase JS wiring** → `auth` agent (placeholder lives in
  `services/auth.ts`).
- **Backend / API contracts** → `backend-engineer` (this repo's `backend/`).
