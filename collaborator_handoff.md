# AIStart360: Руководство по настройке (Handoff)

Этот документ предназначен для разработчиков, работающих над проектом AIStart360. Здесь собраны все необходимые ключи и настройки для запуска проекта в продакшене (Vercel) и локально.

## 1. Настройка Google Cloud Console (OAuth)

Для работы авторизации на домене Vercel необходимо добавить этот домен в список разрешенных.

*   **Домен проекта**: `https://ai-start360-app-client-super-system-xi.vercel.app`
*   **Действие**: 
    1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
    2. Выберите раздел **APIs & Services > Credentials**.
    3. Отредактируйте ваш **OAuth 2.0 Client ID**.
    4. В поле **Authorized redirect URIs** добавьте следующую строку:
       `https://ai-start360-app-client-super-system-xi.vercel.app/api/auth/callback/google`
    5. Нажмите **Save**.
